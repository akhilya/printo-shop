## Design Context

### Users

Покупатель миниатюр (смола / пластик) в России. Заходит с телефона или ноутбука, ищет по названию, смотрит фото, кладёт в корзину, платит Т-Банком. Без аккаунта. Не коллекционер-эксперт на лендинге — обычный магазин.

### Brand Personality

Тихий, предметный, обычный. Голос прямой, без продажи и без сленга хобби. Эмоция: спокойная ясность, как у Yeezy Supply и тихого Shopify, не «wow».

### Aesthetic Direction

Светлая бумага `#FFFFFF`, чернила `#000000`, без акцента. Один гротеск Jost (геометрия Futura, кириллица). Углы 0, теней нет. Фото из PIM как есть, в поле с `contain`. Главная = гибрид (баннер, ряды групп, ряды товаров, баннер каталога). Каталог = `/products`. Корзина — шторка справа. Индивидуальный заказ — форма, не конструктор.

Anti-references: тёмная тема, цветная CTA, Inter, карточки с тенью, тематический декор фигурок, цветные промо-баннеры.

### Design Principles

1. Хром тоньше товара.
2. Цвет только у фото.
3. Одна гарнитура, мало кеглей, сильный контраст размеров.
4. Нет функции — нет элемента (аккаунт, фильтры, избранное).
5. Смешанные фото не обрезать. Рамка 3:4, `contain` — 1:1 садится в неё.
