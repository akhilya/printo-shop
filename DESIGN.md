# Design code

Источник правды для витрины. Характер подтверждён в сессии; палитра — чёрный и белый как Yeezy.

## Character

Тихий, предметный, обычный. Shopify-editorial: воздух, тонкий хром, товар в центре. От Yeezy — дисциплина (нет цвета, нет декора, один гротеск), не лукбук и не чёрный экран.

Это обычный магазин, не «сайт про фигурки». Без вархаммера, смолы и тематического декора.

## Anti

Тёмная тема, акцентный цвет, serif, Inter, градиенты, тени, скруглённые карточки, `object-fit: cover` на фото, боковые фильтры, цветные промо-баннеры, аккаунт, избранное, цветная кнопка.

## Color

| Token | Value | Use |
| --- | --- | --- |
| `--paper` | `#FFFFFF` | фон |
| `--ink` | `#000000` | текст, кнопка, иконки |
| `--ink-45` | `rgb(0 0 0 / 0.45)` | вторичный текст |
| `--hairline` | `#000000` | линии и бордеры |
| `--scrim` | `rgb(0 0 0 / 0.2)` | за шторкой корзины |

Кнопка: фон `--ink`, текст `--paper`. Ховер не серый. Фокус: кольцо 1px `--ink`.

## Type

Одна гарнитура: **Jost** (геометрический гротеск в духе Futura / Yeezy, кириллица). Веса 400 / 500 / 600. Шкала одна на весь магазин — карточка коллекции и карточка товара читаются одним голосом.

| Role | Token | Size | Weight | Tracking | Leading | Где |
| --- | --- | --- | --- | --- | --- | --- |
| caption | `--fs-caption` | 0.75rem (12) | 400 | 0 | 1.4 | подвал, «Нет фото», мелкие подписи |
| ui | `--fs-ui` | 0.875rem (14) | 500 | 0 | 1.35 | навигация, секции, цена, счётчик моделей, пагинация, кнопки |
| body | `--fs-body` | 1rem (16) | 400 / 500 | 0 | 1.5 / 1.25 | заголовок карточки (500, leading 1.25), текст страниц (400) |
| display | `--fs-display` | 2rem (32) | 600 | -0.03em | 1.1 | `h1` страницы, имя товара, заголовки секций |

Карточки (товар и коллекция) делят одну схему:

- фото и стопка сидят на одной нижней кромке; до текста `gap` 16px
- `.card-copy`: заголовок и вторая строка, между ними 4px
- заголовок: 1.125rem / 500, `--ink`, 2 строки clamp
- вторая строка: ui 500, `--ink` — цена (`tabular-nums`) и «N моделей» одним цветом

Секция на главной и на товаре: заголовок = display 600; ссылка «Все коллекции» / «Все товары» = display 600, `--ink`, стрелка справа, подчёркивание по ховеру. Ссылочные кнопки (`a.btn`: баннер, «Индивидуальный заказ») — та же стрелка справа, `currentColor`. Action-кнопки (`button.btn`) без стрелки.

Цены: `tabular-nums`. Акция: текущая цена рядом с зачёркнутой `original` (`--ink-45`), если `calculated_amount` меньше `original_amount`. Промокод — поле на чекауте и в корзине, акции и прайс-листы заводятся в Medusa Admin. Sentence case. Юридический текст `max-width: 65ch`.

Не вводить шестой кегль. Не менять вес заголовка карточки между сетками.

## Space

4pt: 4, 8, 12, 16, 24, 32, 48, 64. `gap`, не margin-коллапс. Углы 0. Теней нет. Шапка 56px.

- `--gutter`: `clamp(24px, 5vw, 48px)` — поля страницы (шапка, `.main`, подвал).
- `--pad`: 48px (`--space-7`) — внутренний отступ баннеров со всех сторон одинаковый.
- Карточка: 16px между фото и текстом.
- Секции главной: 64px и линия.
- Не складывать gutter страницы с pad баннера как разные вертикали внутри одной полосы: у `home_hero` pad равен со всех четырёх сторон.

Контент `max-width: 96rem`, шапка/подвал выровнены с ним.

Сетка карточек: 2 колонки phone, 3–4 desktop, gap 12–16. Ячейка товара: фото в поле 3:4 (`object-fit: contain`, фон `--paper`, бордер 1px `--ink`). 1:1 садится в ту же рамку без обрезки. Нет фото — плейсхолдер «Нет фото».

Карточка коллекции: стопка квадратных «страниц» 1:1 в квадратном кадре. Фото внутри страницы — нативное соотношение, `contain`, без обрезки, целиком в квадрате. Веер без `overflow: hidden` у стопки — запас inset 6%, чтобы страницы были крупнее и не срезались. Без тени, линия `--ink`. Ховер чуть раскрывает веер. `prefers-reduced-motion`: веер статичен.

Карточка товара (страница): галерея не шире 34rem. Не плитка с рамкой. На desktop галерея `sticky` под шапкой, пока справа идут цена, кнопка и характеристики.

На карточке товара — характеристики из PIM как пришли. Если поле не нужно, его не передают.

Главная: между блоками «Коллекции» и «Товары» — 64px и волосок `--hairline`. Без категорийной ленты.

Баннеры — редакционные полосы, не цветной промо. Ширина как у сетки, без вылета за gutter. Верхний (`home_hero`): фон `--ink`, текст `--paper`, pad 48px со всех сторон, заголовок display, текст body, кнопка инверсная (бумага на чернилах). Нижний (`home_catalog`): бумага, волосок сверху, чёрная кнопка. После него (`home_custom`): рамка как у товарного индивидуального заказа, кнопка «Оставить заявку». На товаре (`product_custom`): рамка 1px `--ink` со всех сторон, pad 48px, заголовок display, текст body, чёрная кнопка справа. После характеристик, до карусели коллекции. Тексты главной правятся в админке Medusa. Фото необязательно, `contain`.

## Motion

Шторка: `transform` 280ms `cubic-bezier(0.32, 0.72, 0, 1)` справа, exit тот же путь. Кнопка и карточка `:active { transform: scale(0.97) }` 120ms ease-out. Стрелка ссылочной кнопки: `translateX(3px)` 120ms. Клавиатура — без анимации. Фото: поле `--hairline` пульсирует, затем opacity 180ms. Веер коллекции: 280ms `--ease-drawer`. `prefers-reduced-motion`: только opacity.

## Pages

Главная — отдельная страница, не каталог.

- `/` — гибрид: верхний баннер (цены без комиссии маркетплейсов), несколько рядов коллекций и «Все коллекции», несколько рядов товаров и «Все товары», нижний баннер «весь каталог». Без категорий, без пагинации. Поиск из шапки уводит на `/products?q=`. Старые `/?q=` `/?c=` `/?page=` редирект на `/products`.
- `/products` — все товары. Поиск `?q=`, категория `?c=`, страница `?page=`. Навигация: Товары, Коллекции, категории.
- `/collections` — все коллекции (стопки-страницы). `/groups` редирект сюда.
- `/collections/:id` — товары одной коллекции. `/g/:id` редирект сюда.
- `/p/:handle` — товар, кликабельная коллекция, баннер индивидуального заказа после характеристик, карусель коллекции, отзывы (новые сначала на модерации).
- `/custom-order` — заявка на свою модель. `?product=` привязывает к товару из каталога, но не обязателен.
- шторка корзины
- `/checkout` гостевой, Т-Банк, промокод
- `/checkout/success`, `/checkout/fail`
- `/delivery`, `/offer`, `/contacts`, `/privacy` — юридические страницы, текст и Markdown правятся в админке (Документы). Скрытая страница пропадает из подвала.

На главной: 8 коллекций (два ряда на desktop 4 колонки) и 8 товаров. Полные списки — на `/collections` и `/products`.

Акции: зачёркнутая цена, если sale price list или активная promotion на товар / коллекцию / весь каталог. Промокод на чекауте — отдельно.

## Copy

RU. Кнопки: «В корзину», «Оформить», «Удалить», «Индивидуальный заказ», «Отправить заявку». Секции главной: «Коллекции» / «Все коллекции», «Товары» / «Все товары». Баннер по умолчанию: «В официальном магазине дешевле» / «Весь каталог». Пустой каталог: «Товаров нет». Поиск без результатов: «Ничего не нашли по запросу …». Коллекций нет: «Коллекций пока нет». Заявка: способ связи выбирается селектом (почта / телефон / Telegram / MAX / ВК), затем одно поле. Заявка ушла: «Заявку получили. Напишем вам…». Отзыв ушёл: «Отзыв отправили на модерацию…». Ошибки без вины покупателя. Без имён движка, ключей и английских SDK-текстов. Референсы: до 6 фото, до 2 МБ каждое.

Имя: **PrintO.studio**. Иконка вкладки: `ver4/webp/favico.webp`. В шапке широкий логотип по центру, поиск слева, корзина справа. Поля и бордеры: 1px `--ink`. Фокус: кольцо 1px `--ink` с отступом 4px от бордера.
